How I work

01

Understand the business

I started on the front line, doing the work the software supports. I still start every project there, talking with the people who use the system and finding where time and accuracy are lost.

02

Spec it precisely

I turn that knowledge into user stories and acceptance criteria detailed enough that nothing is lost in handoff, down to individual triggers and fields.

03

Build and prove it with AI

I direct AI coding tools to prototype and build, check the results myself, then measure the impact with real data before and after.

What I've worked on

Areas I've owned, built or am building now, mostly inside a mortgage loan origination system (LOS).

  • UX/UI iteration with AI

    Using AI to prototype and refine screens quickly, including a browser tool that runs real form code so changes can be tested safely.

  • Refinance automation

    Automation that reads loan documents, fills in data and moves refinance loans forward on its own. 40% need no human touch.

  • Refinance seasoning validation

    Automated checks that a refinance meets loan seasoning rules before it moves to the next stage.

  • AI tools for LOS configuration

    An AI integration that lets people search and safely change system setup in plain language, with a human review before every change.

  • LOS custom form design

    Designing and coding the custom input forms loan staff work in every day.

  • LOS custom trigger events

    Business rules that fire on data changes, consolidated and modularized so updates are safer and faster.

  • Property tax proration automation

    Automating how property taxes are split between buyer and seller, with defaults set state by state.

  • Servicing data to LOS integration

    Syncing data from the loan servicing system into the LOS so staff don't re-key it.
